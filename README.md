## 最关键的细节：10Gbps大带宽，回国直连只有10Mbps

这是绿云香港套餐最容易被忽略、也最影响使用体验的一条限制。绿云官方在产品页面写得清清楚楚：香港VPS到中国大陆的直连带宽只有10Mbps，日本节点给的是1Gbps Best-Effort。

什么概念呢？10Mbps 够你网页浏览、SSH 管理、跑个低流量网站，但晚高峰想看高清视频、走代理看流媒体，这个口子会成为瓶颈。套餐页面上那个显眼的10000Mbps端口，跑的是国际方向流量，去新加坡、美国、日本这些地方大带宽是真的；到中国大陆，就是10Mbps这条窄路。

为什么第三方评测大多不提这个？因为大家习惯看 ping 值和跑分，ping 到香港几十毫秒看着很美，但 ping 值不等于带宽，回程路由和直连带宽是另一回事。这条信息只写在官方产品页的备注里，不在任何套餐宣传图上，算得上绿云香港VPS评测里最值得先说清楚的一点。

## 普通线路和CN2 GIA差在哪：拿搬瓦工算笔账

绿云香港DC2系列在比价数据库里被标注为“普通线路”，没有CN2 GIA、联通9929、移动CMIN2这类中国优化路由。普通线路走国际转接，白天延迟看着不高，晚高峰丢包率上来的情况在低价VPS里很常见。

要买真香港优化线路，价格是什么量级？搬瓦工（BandwagonHost）的香港CN2 GIA套餐可以作为参照：入门款2核2GB、40GB SSD、每月500GB流量，$46.70季付，折合约$15.57/月；更高一档的Premium款同样配置换NVMe存储，$899.99/年。同样2GB内存的配置，绿云年付25美元，搬瓦工香港月付15美元以上，差出近一个数量级。

这个差价买的不是智商税，是线路。香港CN2 GIA的IP transit成本本身就贵，商家卖得贵有物理原因。所以决策逻辑很简单：

- 晚高峰要稳定服务大陆用户、跑视频会议、对延迟丢包敏感 → 优化线路产品，绿云香港满足不了

## 常见问题

**绿云香港VPS能跑满10Gbps吗？**

端口标称10Gbps，国际方向可以期待高带宽，但共享端口和实际路由质量会打折扣，且回国方向固定10Mbps直连。把它当“10Gbps大水管”用在国际传输上比较现实。

**年付25美元续费还是这个价吗？**

没有官方来源确认EPYCHKDC2系列的续费价格与首年一致。促销年付套餐在很多商家的惯例里续费会恢复原价，下单时在结账页确认续费价，或者把它当一年期消耗品来规划预算。

**这个套餐退款吗？**

不支持。EPYCHKDC2-1 明确标注 "No refund/Money back on this plan"，绿云历次促销活动也注明促销计划不可退款。想降低试错风险，先买6美元/月的KVMHK2-1测一个月。

**支持Windows吗？**
